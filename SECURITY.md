# Security

This project is in development and intended for local research. It has no broker integration and should not be exposed as a public web service.

Keep credentials in the environment or a local .env file. Databases, model caches, and chat histories can contain private research context; do not commit them or attach them to public issues.

To report a vulnerability, use the repository's private vulnerability reporting feature on GitHub if available. Do not disclose keys or exploitable details in a public issue. If private reporting is unavailable, open a minimal issue asking for a private contact channel without including the vulnerability details.

Reports should describe the affected version, conditions, and a minimal example with synthetic data.
