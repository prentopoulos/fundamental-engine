# Changelog

## 0.1.0 — Initial public development release

- Explainable macroeconomic research board with separate policy and directional axes.
- Current evidence and forward calendar expectations kept distinct.
- Configurable recency decay, material breadth, instrument weights, and attention ranking.
- Local dashboard, command-line passes, optional scheduler/chat, and read-only MCP.
- Free offline demo using fictional scenarios and an isolated temporary database.
- Offline tests, CI, and public methodology and run guides.
